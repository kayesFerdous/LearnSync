# Contributing to LearnSync

Thanks for your interest in contributing to LearnSync — appreciate it!

## How to contribute

- Fork the repository and create a feature branch.
- Keep changes small and focused; open a pull request against `main`.
- Write clear commit messages and include tests where appropriate.
- For docs, update `README.md` or add markdown files in the repo root.

## Reporting issues

- Please open issues with a clear title and description, steps to reproduce, and any relevant logs.

## Code style

- Python: follow PEP8 and use black/isort for formatting.
- TypeScript / Frontend: follow the project's ESLint and Prettier settings.

## Pull requests

- PRs should include a description of the change, motivation, and testing notes.
- Maintain backward compatibility; avoid breaking changes in minor/patch PRs.

## Welcome!

I welcome contributors of all backgrounds. If you want to help with onboarding or mentoring, please open an issue.
